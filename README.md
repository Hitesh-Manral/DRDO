1. Navigate to the project directory:

   ```bash
   cd [project_directory]
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure the database:

   - Set up SQL and update the database configuration.

   - DB name:fixi_db
   - For backend
     ```bash
     node server.js
     ```

4. Run the application:
   ```bash
   npm run dev
   ```
